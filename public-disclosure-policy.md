# Public Disclosure Policy

## What Can Be Public

The following may be shared publicly:

- high-level architecture
- sanitized screenshots
- validation summaries
- release summaries
- non-sensitive documentation
- project goals and learning outcomes

## What Must Stay Private

Do not publish:

- full source code
- real `.env` files
- database files
- upload files
- logs
- backups
- production configuration
- API keys
- tokens
- passwords
- private infrastructure details
- exploit implementation details
- internal execution logic

## Screenshot Rules

Before publishing screenshots, remove or blur:

- usernames/emails unless intentionally public
- local or private IP addresses
- domains
- tokens
- API keys
- session values
- real file names if sensitive
- system paths that reveal personal information

## Licensing

This documentation-only portfolio repository may remain unlicensed or use a documentation-focused license.  
The private implementation repository should remain private and should not be given an open-source license unless commercialization plans are abandoned.
